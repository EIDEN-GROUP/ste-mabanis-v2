# STE MABANIS Digital Showcase

Create the premium public website for STE MABANIS, a Moroccan real-estate agency.

IMPORTANT: This prompt is ONLY for the public website. Do not build the admin/CRM yet.

Use the attached STE MABANIS logo exactly as provided.

TYPOGRAPHY:

Sarabun Light for navigation, UI, search, buttons and body text

Playfair Display for hero titles, editorial headings and property titles
(stands in for Safira March, which has no web-font CDN — self-host it and swap
the --font-display stack in src/styles.css to use the real face)

Roboto only inside the back office, scoped by the `font-admin` utility

CONTENT STYLE:
The website should communicate expertise, trust, local knowledge and premium service.

Use realistic Moroccan real-estate content and MAD prices.
Do NOT use lorem ipsum.

The tone should be sophisticated but human, not overly corporate.

UX:
The website should convert visitors into:

property inquiries

valuation requests

visit requests

contact requests

Every important CTA should be clear and connected conceptually to the future CRM.

ANIMATIONS:

LOADER:
Create a branded STE MABANIS loader using the attached logo:
dark navy background + subtle champagne-gold animation + elegant page reveal.
Do not use a generic spinner.

RESPONSIVE:
Build a dedicated responsive experience for desktop, tablet and mobile.
Pay particular attention to mobile property browsing, filters, galleries, navigation and contact/visit CTAs.

FINAL DIRECTION:

The website should feel like:

+

It should be visually impressive like the provided references, while remaining practical, fast, accessible and conversion-focused.

Do not create a generic real-estate template.
Create a distinctive STE MABANIS digital identity.
